## 💻 Descripción del Proyecto
Este proyecto inicial sirve como base fundamental para el diseño, estructura y construcción de aplicaciones funcionales utilizando el lenguaje de programación Java. Está enfocado en resolver problemas lógicos y estructurar código limpio y mantenible.

### 🎯 Objetivos de Aprendizaje:
* Dominio de la sintaxis y tipos de datos en Java.
* Implementación de estructuras condicionales y repetitivas.
* Aplicación de principios de la Programación Orientada a Objetos (POO).
* Gestión básica de entrada y salida de datos a través de la consola o entornos gráficos.

## 🛠️ Tecnologías y Entorno de Desarrollo
* **Lenguaje de Programación:** Java
* **IDE Recomendado:** Apache NetBeans / IntelliJ IDEA / Eclipse
* **Control de Versiones:** Git y GitHub
